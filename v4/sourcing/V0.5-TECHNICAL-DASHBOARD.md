# V4 Sourcing Intelligence — V0.5 Technical Dashboard

## Purpose
Independent Sourcing Intelligence cockpit: Radar → Analyse → Coût rendu → Rentabilité → Fournisseur → Échantillon/QC → Décision.

## Screens
1. Control Center
2. Nouvelle opportunité
3. Offres fournisseurs
4. Analyse économique
5. Comparaison
6. Fiche fournisseur
7. Échantillon + QC
8. Décision

## Core data
- Opportunity: product, country, target price, target margin, max landed cost, MOQ, constraints.
- Offer: supplier, unit price, MOQ, customization, packaging, logistics, lead time, payment terms, evidence/confidence.
- Economics: landed cost, selling price, variable fees, CAC, contribution, contribution margin, max CAC, minimum selling price.
- Supplier: identity, source, contact status, reliability signals, risk, notes.
- QC: sample status, inspection checks, defects, decision.

## Decision flow
RADAR → ANALYSE → VÉRIFICATION → CALCUL → DÉCISION.
States: ACHETER / TESTER / ATTENDRE / ÉVITER.

## Scoring
100-point composite using profitability, MOQ, landed-cost fit, confidence/evidence, supplier/risk and testability. The score is advisory; hard economic constraints must still block unsafe conclusions.

## UX principles
- Control Center Premium Intelligence.
- Inter typography.
- Mobile-first.
- Calm dark graphite cockpit, high contrast, restrained accent colors.
- Progressive disclosure: summary first, details on demand.
- Fennec remains the visual signature, not decoration.
- Every primary screen exposes one clear next action.

## Critical validation
- Never hide missing data behind a score.
- Distinguish estimated vs verified values.
- Landed-cost engine remains the calculation source of truth.
- Do not modify V0.4 engines until tests/compatibility are confirmed.
- No change to main as part of V0.5 implementation.
